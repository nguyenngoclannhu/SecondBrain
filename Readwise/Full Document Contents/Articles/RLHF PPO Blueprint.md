##### Frontier AI by hand ✍️

In this week’s [Frontier](https://substack.com/redirect/e09d67fd-1fc0-43af-bf93-0a0d8f6576b6?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI_zv_M4N2A50pyRXMoP1g) issue, I’m sharing the initial results of my research to break down RLHF PPO into a fully traceable AI by Hand ✍️ Excel Blueprint.

RLHF PPO = Reinforcement Learning from Human Feedback (RLHF) trained with Proximal Policy Optimization (PPO). Popularized by OpenAI, it has since become widely used across the industry to align large language models.

[![](https://substackcdn.com/image/fetch/$s_!tPMk!,w_1100,c_limit,f_auto,q_auto:good,fl_progressive:steep/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2Fed5f8f1d-2aca-48b4-8c53-32f8eef90226_1874x1054.png)](https://substack.com/redirect/ed5a3680-762d-4197-9b57-67fe3ad4a96e?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI_zv_M4N2A50pyRXMoP1g)If I had to nominate the most complex loss function used in frontier AI, there’s no doubt: it’s RLHF.

For perspective, here is the loss for Generative Adversarial Networks (GANs), which many of my students already consider very complicated. A GAN has:

* two loss terms combined for the **Generator**, and
* one loss for the **Discriminator**

So in total: about three moving pieces, like this:

[![](https://substackcdn.com/image/fetch/$s_!ZdAJ!,w_1100,c_limit,f_auto,q_auto:good,fl_progressive:steep/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2F62b4258e-a8c6-472f-afa6-d0982f1f56f5_1034x467.png)](https://substack.com/redirect/aa454534-af4f-430f-8ed6-08313de531f1?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI_zv_M4N2A50pyRXMoP1g)For **RLHF**, there are close to 20 pieces you must somehow put together. Just to list a few:

* policy loss (PPO clip)
* value loss
* policy KL (current vs previous)
* reference KL (current vs SFT base)
* reward model coupling
* GAE advantage estimation
* proximity model (θold)
* reference model (θref)
* importance sampling ratios
* value targets from old model
* sequence-level credit assignment
* token-level advantage weighting
* many more ….

#### Design

**Prerequisites:** This Blueprint is aimed at those of you who have already worked with RLHF in some capacity but want extra help connecting your technical experience to the underlying math. It is **not** designed as a first introduction to RLHF. If you’d like a high-level overview of RLHF before diving in, I recommend this excellent [interview](https://substack.com/redirect/0772c8f5-b391-4636-ac55-554e5485fe7f?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI_zv_M4N2A50pyRXMoP1g) with Nathan Lambert, author of the [RLHF book](https://substack.com/redirect/a7de8dd9-47d7-4eac-8fc3-3bb57af0dc3f?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI_zv_M4N2A50pyRXMoP1g). 

**Language Model:** I use an autoregressive RNN as the language model instead of a transformer stack so you can focus entirely on the RLHF component, which works the same way regardless of architecture. The RNN keeps the example simple and avoids unnecessary distraction.

[![](https://substackcdn.com/image/fetch/$s_!JSr9!,w_1100,c_limit,f_auto,q_auto:good,fl_progressive:steep/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2Fd38107b7-1fe6-41d3-8687-b3c25ee8c09c_1102x1272.png)](https://substack.com/redirect/9640a984-8f6d-4ea2-9aff-82361e083354?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI_zv_M4N2A50pyRXMoP1g)**Reward Model:** I started from the point after the reward model is already trained; I’ll create a separate Blueprint for reward-model training later.

[![](https://substackcdn.com/image/fetch/$s_!f0ok!,w_1100,c_limit,f_auto,q_auto:good,fl_progressive:steep/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2F0ce47f4b-5a01-44e1-95d4-1d21c907fe32_580x816.png)](https://substack.com/redirect/80d90cc5-c9dd-4c65-aef6-26134e2660ea?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI_zv_M4N2A50pyRXMoP1g)**Policy Gradient:** The loss function is fully implemented, but the policy-gradient update is simulated for clarity, since the goal is to break down this notoriously confusing loss function step by step. In other words, I didn’t implement backpropagation here.

<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;"><strong>Prerequisites:</strong><span> This Blueprint is aimed at those of you who have already worked with RLHF in some capacity but want extra help connecting your technical experience to the underlying math. If you’d like a high-level overview of RLHF before diving in, I recommend this excellent </span><a href="https://substack.com/redirect/0772c8f5-b391-4636-ac55-554e5485fe7f?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI\_zv\_M4N2A50pyRXMoP1g" rel="" style="color: rgb(54,55,55);text-decoration: underline;">interview</a><span> with Nathan Lambert, author of the </span><a href="https://substack.com/redirect/a7de8dd9-47d7-4eac-8fc3-3bb57af0dc3f?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI\_zv\_M4N2A50pyRXMoP1g" rel="" style="color: rgb(54,55,55);text-decoration: underline;">RLHF book</a><span>. </span></p>
<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;"><strong>Language Model: </strong><span>I use an autoregressive RNN as the language model instead of a transformer stack so you can focus entirely on the RLHF component, which works the same way regardless of architecture.
