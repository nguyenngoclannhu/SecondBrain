## Full Document
##### Foundation AI Seminar Series

My next Foundation seminar will be about TPUs. I’ll take you from the 0/1 bits all the way to high-bandwidth memory (HBM) in a beginner-friendly way by hand ✍️. 

I’m excited to be joined by a special guest expert, [Shanya Chaubey](https://substack.com/redirect/f11d6f73-5f6a-4377-b973-f8bbd4a85ac6?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI_zv_M4N2A50pyRXMoP1g) from Micron Technology, who will help answer your HBM questions live in the chat—since her company is a major HBM supplier for Google’s new Ironwood TPUs.

Here’s an early sketch of the memory hierarchy drawing I’ve created for this seminar:

[![](https://substackcdn.com/image/fetch/$s_!1nKP!,w_1100,c_limit,f_auto,q_auto:good,fl_progressive:steep/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2F3d76db4b-ae72-4d58-ae67-ae23d1577fe0_1198x1138.png)](https://substack.com/redirect/2601b2a2-097c-4da2-b4df-f4c4d3ea34e3?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI_zv_M4N2A50pyRXMoP1g)1. **Bit** – The most basic unit of information, the on–off decision from which every number, tensor, and model state is ultimately constructed.
2. **FP8 (1×8 → 8 bits)** – Eight bits are grouped to form a floating-point value, typically used for inference, where reduced precision is a deliberate trade-off to maximize throughput and efficiency.
3. **BF16 (×2 → 16 bits)** – Two FP8-scale chunks are combined to gain more dynamic range and stability, while still staying friendly to high-throughput hardware.
4. **Tensor tile (×1024 → 1K)** – Data moves through the chip in blocks of 1024 values at a time, defining the granularity at which tensors are fetched and manipulated.
5. **Matrix Multiplication Unit (MXU) (×64 → 64K)** – A systolic array where matrix multiplication is not abstract but physical, with tensor tiles flowing through fixed hardware to achieve the highest possible throughput.
6. **Vector Memory (VMEM) (×2048 → 128M)** – On-chip working memory that holds activations, partial results, and intermediates, sized specifically to keep the systolic array busy without stalling.
7. **Common Memory (CMEM) (×8 → 1 GB)** – A small but critical shared memory sitting between VMEM and HBM, used for staging, accumulation, synchronization, and cross-lane coordination.
8. **HBM (×96 → 96 GB)** – Off-chip high-bandwidth memory where model weights and large states live, implemented as HBM3e with 16 stacks at 6 GB each, for a total of 96 GB.

<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;margin-top: 0;">My next Foundation seminar will be about TPUs. I’ll take you from the 0/1 bits all the way to high-bandwidth memory (HBM) in a beginner-friendly way by hand ✍️. </p>
<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;"><span>I’m excited to be joined by a special guest expert, </span><a href="https://substack.com/redirect/f11d6f73-5f6a-4377-b973-f8bbd4a85ac6?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI\_zv\_M4N2A50pyRXMoP1g" rel="" style="color: rgb(54,55,55);text-decoration: underline;">Shanya Chaubey</a><span> from Micron Technology, who will help answer your HBM questions live in the chat—since her company is a major HBM supplier for Google’s new Ironwood TPUs.</span></p>
<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;">Here’s an early sketch of the memory hierarchy drawing I’ve created for this seminar:</p>

<ol style="margin-top: 0;padding: 0;">
<li style="margin: 8px 0 0 32px;"><p style="color: rgb(54,55,55);line-height: 26px;margin-bottom: 0;box-sizing: border-box;padding-left: 4px;font-size: 16px;margin: 0;"><strong>Bit</strong><span> – The most basic unit of information, the on–off decision from which every number, tensor, and model state is ultimately constructed.</span></p></li>
<li style="margin: 8px 0 0 32px;"><p style="color: rgb(54,55,55);line-height: 26px;margin-bottom: 0;box-sizing: border-box;padding-left: 4px;font-size: 16px;margin: 0;"><strong>FP8 (1×8 → 8 bits)</strong><span> – Eight bits are grouped to form a floating-point value, typically used for inference, where reduced precision is a deliberate trade-off to maximize throughput and efficiency.</span></p></li>
<li style="margin: 8px 0 0 32px;"><p style="color: rgb(54,55,55);line-height: 26px;margin-bottom: 0;box-sizing: border-box;padding-left: 4px;font-size: 16px;margin: 0;"><strong>BF16 (×2 → 16 bits)</strong><span> – Two FP8-scale chunks are combined to gain more dynamic range and stability, while still staying friendly to high-throughput hardware.</span></p></li>
<li style="margin: 8px 0 0 32px;"><p style="color: rgb(54,55,55);line-height: 26px;margin-bottom: 0;box-sizing: border-box;padding-left: 4px;font-size: 16px;margin: 0;"><strong>Tensor tile (×1024 → 1K)</strong><span> – Data moves through the chip in blocks of 1024 values at a time, defining the granularity at which tensors are fetched and manipulated.</span></p></li>
<li style="margin: 8px 0 0 32px;"><p style="color: rgb(54,55,55);line-height: 26px;margin-bottom: 0;box-sizing: border-box;padding-left: 4px;font-size: 16px;margin: 0;"><strong>Matrix Multiplication Unit (MXU) (×64 → 64K)</strong><span> – A systolic array where matrix multiplication is not abstract but physical, with tensor tiles flowing through fixed hardware to achieve the highest possible throughput.</span></p></li>
<li style="margin: 8px 0 0 32px;"><p style="color: rgb(54,55,55);line-height: 26px;margin-bottom: 0;box-sizing: border-box;padding-left: 4px;font-size: 16px;margin: 0;"><strong>Vector Memory (VMEM) (×2048 → 128M)</strong><span> – On-chip working memory that holds activations, partial results, and intermediates, sized specifically to keep the systolic array busy without stalling.</span></p></li>
<li style="margin: 8px 0 0 32px;"><p style="color: rgb(54,55,55);line-height: 26px;margin-bottom: 0;box-sizing: border-box;padding-left: 4px;font-size: 16px;margin: 0;"><strong>Common Memory (CMEM) (×8 → 1 GB)</strong><span> – A small but critical shared memory sitting between VMEM and HBM, used for staging, accumulation, synchronization, and cross-lane coordination.</span></p></li>
<li style="margin: 8px 0 0 32px;"><p style="color: rgb(54,55,55);line-height: 26px;margin-bottom: 0;box-sizing: border-box;padding-left: 4px;font-size: 16px;margin: 0;"><strong>HBM (×96 → 96 GB)</strong><span> – Off-chip high-bandwidth memory where model weights and large states live, implemented as HBM3e with 16 stacks at 6 GB each, for a total of 96 GB.</span></p></li>
</ol>
