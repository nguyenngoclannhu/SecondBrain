## Full Document
##### Frontier AI Seminar

One of the clearest *engineering trends* in agentic AI today is the growing use of **small language models (SLMs)** inside agent loops.

[![User Uploaded Image](https://substackcdn.com/image/fetch/$s_!U9Sb!,w_1100,c_limit,f_auto,q_auto:good,fl_progressive:steep/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2F956f9aa1-ff46-4123-8b37-3c79e7391672_1600x1008.jpeg "User Uploaded Image")](https://substack.com/redirect/17c8abe0-ee3c-4e98-9b06-a1dc619b3e38?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI_zv_M4N2A50pyRXMoP1g)This is not because SLMs outperform large models across the board. Rather, many agent workloads place real constraints on latency, cost, deployment footprint, and controllability—constraints under which smaller models are often a practical choice, especially when the core task is *tool invocation* rather than*long-form generation*.

Last December right before many of us slowed down to enjoy the holidays with families, **Amazon Web Services** released [a study examining how SLMs perform on tool-calling tasks](https://substack.com/redirect/de44e176-ea9c-4efe-a275-b3fee4fbbb78?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI_zv_M4N2A50pyRXMoP1g).

What makes this study a big deal is not the headline numbers, but the fact that a major technology company chose to publicly document, in detail, how a small language model can be trained, stabilized, and evaluated for tool use in a production-oriented setting.

Much of the public discussion so far has focused on results.

In the next **Frontier seminar**, I want to focus on the *mechanics*.

Specifically, I will address **five important questions** motivated by this study**:**

1. **SLM:** What is OPT-350M, the small language model used by AWS?
2. **SFT:** What is ToolBench-style Supervised Fine Tuning?
3. **ToolBench:** How is ToolBench data turned into training examples?
4. **Loss:** What loss is optimized during tool-use training?
5. **Stability:** Why does this setup remain stable in a single epoch?

I’m also excited to share that this session will feature a **special guest: Dr. Xu Han from Amazon**, who will share her first-hand experience training small language models for one of Amazon’s key products.

Curious which product? You’ll find out during the seminar which product she has been responsible for—and what practical lessons emerged from training SLMs in a production setting.

The goal of this seminar is not to argue that SLMs replace large models, but to understand *why SLMs are increasingly used in agentic systems*, and what that implies for training, evaluation, and deployment.

As always, I’ll teach this **by hand** ✍️.

<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;margin-top: 0;"><span>One of the clearest </span><em>engineering trends</em><span> in agentic AI today is the growing use of </span><strong>small language models (SLMs)</strong><span> inside agent loops.</span></p>
<div style="font-size: 16px;line-height: 26px;margin: 32px auto;"><figure style="width: 100%;margin: 0 auto;"><table border="0" cellpadding="0" cellspacing="0" data-component-name="Image2ToDOMStatic" style="mso-padding-alt: 1em 0 1.6em;" width="100%"><tbody><tr>

<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;"><span>This is not because SLMs outperform large models across the board. Rather, many agent workloads place real constraints on latency, cost, deployment footprint, and controllability—constraints under which smaller models are often a practical choice, especially when the core task is </span><em>tool invocation</em><span> rather than</span><strong> </strong><em>long-form generation</em><span>.</span></p>
<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;"><span>Last December right before many of us slowed down to enjoy the holidays with families, </span><strong>Amazon Web Services</strong><span> released </span><a href="https://substack.com/redirect/de44e176-ea9c-4efe-a275-b3fee4fbbb78?j=eyJ1IjoiNnE2ZWdsIn0.JeUaI03hkTZe3g0Y-WbKcpI\_zv\_M4N2A50pyRXMoP1g" rel="" style="color: rgb(54,55,55);text-decoration: underline;">a study examining how SLMs perform on tool-calling tasks</a><span>.</span></p>
<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;">What makes this study a big deal is not the headline numbers, but the fact that a major technology company chose to publicly document, in detail, how a small language model can be trained, stabilized, and evaluated for tool use in a production-oriented setting.</p>
<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;">Much of the public discussion so far has focused on results.</p>
<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;"><span>In the next </span><strong>Frontier seminar</strong><span>, I want to focus on the </span><em>mechanics</em><span>.</span></p>
<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;"><span>Specifically, I will address </span><strong>five important questions </strong><span>motivated by this study</span><strong>:</strong></p>
<ol style="margin-top: 0;padding: 0;">
<li style="margin: 8px 0 0 32px;"><p style="color: rgb(54,55,55);line-height: 26px;margin-bottom: 0;box-sizing: border-box;padding-left: 4px;font-size: 16px;margin: 0;"><strong>SLM:</strong><span> What is OPT-350M, the small language model used by AWS?</span></p></li>
<li style="margin: 8px 0 0 32px;"><p style="color: rgb(54,55,55);line-height: 26px;margin-bottom: 0;box-sizing: border-box;padding-left: 4px;font-size: 16px;margin: 0;"><strong>SFT:</strong><span> What is ToolBench-style Supervised Fine Tuning?</span></p></li>
<li style="margin: 8px 0 0 32px;"><p style="color: rgb(54,55,55);line-height: 26px;margin-bottom: 0;box-sizing: border-box;padding-left: 4px;font-size: 16px;margin: 0;"><strong>ToolBench:</strong><span> How is ToolBench data turned into training examples?</span></p></li>
<li style="margin: 8px 0 0 32px;"><p style="color: rgb(54,55,55);line-height: 26px;margin-bottom: 0;box-sizing: border-box;padding-left: 4px;font-size: 16px;margin: 0;"><strong>Loss:</strong><span> What loss is optimized during tool-use training?</span></p></li>
<li style="margin: 8px 0 0 32px;"><p style="color: rgb(54,55,55);line-height: 26px;margin-bottom: 0;box-sizing: border-box;padding-left: 4px;font-size: 16px;margin: 0;"><strong>Stability:</strong><span> Why does this setup remain stable in a single epoch?</span></p></li>
</ol>
<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;"><span>I’m also excited to share that this session will feature a </span><strong>special guest: Dr. Xu Han from Amazon</strong><span>, who will share her first-hand experience training small language models for one of Amazon’s key products.</span></p>
<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;">Curious which product? You’ll find out during the seminar which product she has been responsible for—and what practical lessons emerged from training SLMs in a production setting.</p>
<p style="margin: 0 0 20px 0;color: rgb(54,55,55);line-height: 26px;font-size: 16px;"><span>The goal of this seminar is not to argue that SLMs replace large models, but to understand </span><em>why SLMs are increasingly used in agentic systems</em><span>, and what that implies for training, evaluation, and deployment.</span></p>
