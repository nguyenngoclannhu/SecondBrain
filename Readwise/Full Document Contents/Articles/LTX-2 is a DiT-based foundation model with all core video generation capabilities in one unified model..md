The first truly open-source audio-video model.

(19B params, runs 100% locally)

LTX-2 is a DiT-based foundation model with all core video generation capabilities in one unified model.

Here's what makes it stand out:

🎬 Synchronized audio + video generation  

⚡ Multiple pipelines (fast distilled or production-quality two-stage)  

🎮 Camera control LoRAs (dolly, jib, static shots)  

🖼️ Text-to-video, image-to-video, and video-to-video modes  

🧠 19B parameter model with FP8 support for lower memory  

🆓 Fully open-source with training tools included

And you don't need to worry about crafting the perfect prompt; automatic prompt enhancement refines your input for better video output.
